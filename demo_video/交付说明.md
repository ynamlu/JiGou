# 演示视频交付说明（人工配音 + 人工录屏）

> 分工：你负责配音和录屏；我方负责静态页、字幕、配乐/混音、剪辑与最终成片。
> 目标成片：5–8 分钟，1920×1080，MP4，H.264 + AAC，字幕烧录。

## 一、已经给你准备好的

| 位置 | 内容 |
| --- | --- |
| `demo_video/静态页/01-…png` … `21-…png` | 21 张 1920×1080 静态页，按顺序编号 |
| `demo_video/静态页/静态页总览.pptx` | 同上，16:9 全屏 PPT，方便预览/投屏 |
| `demo_video/配音稿.md` | 按 B01–B20 分镜的逐段文案，可直接照读 |

## 二、你需要回传的素材

建议建一个 `交付素材/` 文件夹：

```text
交付素材/
├── 配音/
│   ├── B01.wav
│   ├── B02.wav
│   ├── …
│   └── B20.wav
├── 录屏/
│   ├── B10.mp4
│   ├── B11.mp4
│   ├── …
│   └── B19.mp4
└── 备注.md          # 可选：哪段重录过、哪段想换顺序
```

### 配音要求

- 按 `配音稿.md` 一段一段录，文件名与分镜号一致；
- 48kHz / 24bit WAV，单声道或立体声均可；
- 每段前后留 0.5–1 秒静音，方便剪辑；
- 目标响度 -16 LUFS，安静环境、无明显底噪/混响；
- 不必严格卡参考时长，语速自然即可；
- 如果只能录一整条，也请同时给出每段大致起止时间，或严格按稿子顺序读。

### 录屏要求

- 1920×1080，30fps 或 60fps，H.264 / VP9 / WebM 均可；
- 按 B10–B19 分段录，每段前后留 1 秒静止；
- 浏览器缩放 100%，隐藏书签栏和通知；
- 滚动要连续缓慢，不要滚轮一格一格跳；
- 关键操作（登录、发送、一键确认、导出）要完整；
- 不要录到 API Key、终端、隐私路径；手机号可后期打码。

## 三、字幕怎么处理

你**不需要自己做字幕**。

- 我方会根据你按分镜录的音频，用静音检测 + 文案对齐，生成 SRT / ASS；
- 字幕字号、位置、描边按 1080p 统一处理；
- 如果你已经有一版 SRT，也可以一起发来，我优先用你的时间轴。

## 四、最终我交付什么

- `极构-需求诊断顾问-演示视频-成片.mp4`：1080p、H.264、AAC、烧录字幕；
- 字幕源文件 `.srt` / `.ass`；
- 如需要，另出无字幕版和封面图。

## 五、合成顺序建议

1. B01–B09：静态页 + 你的配音（概念/功能/技术栈）；
2. B10–B19：你的录屏 + 你的配音；
3. B20：结尾静态页 + 配音；
4. 统一 25fps 或 30fps 时间线，字幕烧录，混音到 -16 LUFS。

如果某段录屏或配音不满意，单独重录那一段即可，不需要全部重来。
