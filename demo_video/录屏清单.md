# 录屏清单（人工录制版）

> 只录 B10–B19 的操作片段。静态页、字幕、最终剪辑由我方处理。
> 每段单独录一个文件，命名与分镜号一致，例如 `B10.mp4`、`B13.mp4`。

## 通用要求

- 分辨率 **1920×1080**，帧率 **30fps 或 60fps**（不要用 25fps 以下）；
- 浏览器缩放 100%，隐藏书签栏、通知和输入法候选框；
- 每段前后各留 **1 秒**静止画面，方便剪辑；
- 鼠标移动放慢，点击前停 0.4–0.6 秒；
- 滚动页面请**连续、缓慢**地滚，不要用滚轮一下一下跳；
- 不要录到 API Key、终端、本地隐私路径；手机号可后期打码；
- 如果某段录坏了，单独重录该段即可，不用重录全部。
