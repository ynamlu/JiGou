# 演示视频脚本（5–8 分钟）

> 目标：5–8 分钟，1080p，MP4，普通话讲解，可配字幕。
> 建议成片 6 分 40 秒左右，留出剪辑余量。

## 一、录制前准备

**环境**

- 分辨率 1920×1080，浏览器缩放 100%，关闭无关标签页与通知；
- 提前执行 `python run.py`，确认 `/api/health` 返回 `key_configured: true`；
- 准备测试账号 `13800138000` / `Demo@123456`（`backend/seed_demo.py` 可重建），并提前生成 1 份带「待确认事项」的报告，避免录制时等待模型；
- 需要现场演示一次对话时，问题尽量短，减少等待。

**素材**

- PPT 或封面页 1 张（项目名、赛道、团队）；
- 架构图：`docs/diagrams/architecture.png`；
- 报告截图备份：`docs/screenshots/report-desktop.jpg`（防止网络抖动）。

**设备**

- 麦克风离嘴 15–20cm，录前试音；
- 录屏软件：OBS / EV 录屏，输出 1080p 30fps；
- 剪辑：剪映 / PR，导出 H.264 + AAC。

## 二、分镜与口播

### 00:00–00:40 开场（40 秒）

**画面**：封面页 → 首页 Hero。

**口播**：

> 大家好，我们是极构团队，参赛作品是「极构 · 需求诊断顾问」，参加 AI WEB 网页开发挑战赛。
> 我们解决的问题很具体：很多创业者和个体店主想做一个系统，却说不清要做什么、大概多少钱、还缺哪些准备。
> 极构用 AI 把一句「我想做个系统」，变成一份可以直接拿去开发、询价、立项的需求报告。

### 00:40–01:30 账号与首页（50 秒）

**操作**：打开 `http://127.0.0.1:8000` → 登录页 → 注册/登录 → 首页。

**口播**：

> 系统是本地运行的完整 Web 应用，前端 Vue 3，后端 FastAPI，数据存在本地 SQLite。
> 第一次使用先注册，手机号加强度校验的密码；登录后进入首页。
> 首页给出两种诊断方式：问卷适合还说不清的人，自由对话适合已经有想法的人。

### 01:30–02:40 问卷演示（70 秒）

**操作**：开始需求分析 → 按问卷答题 → 连续答 2–3 题（形态、用户、预算）→ 展示「补充说明」→ 展示上一题。

**口播**：

> 问卷不是固定题库，而是 AI 根据上一题动态生成下一题。
> 比如我先选「微信小程序」，再说给门店顾客用，它会继续追问核心功能和预算。
> 每道题都可以补充说明，也可以回上一题修改。信息够了，它会主动收尾，而不是没完没了地问。

### 02:40–03:50 自由对话与 RAG（70 秒）

**操作**：放弃问卷（或新开对话）→ 自由对话 → 输入一句需求 → 展示「正在检索知识库」→ 流式回答。

**口播**：

> 自由对话走的是 Agent：它会先检索自建的 12 篇软件开发知识库，再按「已具备、还缺失、待确认」三段回答。
> 前端通过 NDJSON 接收事件，所以能看到检索状态和逐字输出。
> 检索有两条通道：Chroma 向量检索，以及 BM25 关键词检索；向量服务不可用时会自动降级，保证离线也能演示。

### 03:50–05:00 报告、评分与交付物（70 秒）

**操作**：生成报告 → 报告详情 → 六维评分 → 待确认事项 → 交付物三件套 → A/B 方案。

**口播**：

> 生成后会得到一份五段式诊断报告：项目概述、已具备、还缺失、待确认清单、建议下一步。
> 同时给出六维成熟度评分和风险提示，再把需要拍板的事项逐条列出来。
> 继续可以生成 PRD、开发询价清单、成本工期估算，以及 MVP 和完整版两套 A/B 方案。
> 这些不是聊天记录，而是可以直接发给开发方、用来比价和验收的材料。

### 05:00–05:50 验收、版本与导出（50 秒）

**操作**：逐项选择确认/不涉及/补充 → 确认验收 → 展示凭证与 v1 → 发起修订 → 验收 v2 → 查看 diff → 导出 PDF。

**口播**：

> 验收时逐项拍板，系统会计算报告指纹、生成版本号和与上一版的差异。
> 以后改需求，能清楚看到每一版确认了什么，避免口头扯皮。
> 报告支持 Markdown、PDF 和长截图导出，也可以直接在手机上查看。

### 05:50–06:40 技术亮点（50 秒）

**画面**：切到架构图，配合简单标注。

**口播**：

> 技术上有四个亮点。
> 第一，Agent 工作流：工具调用、会话记忆、结构化输出都在一条链路里。
> 第二，RAG 双通道自动降级：向量检索失败不影响演示。
> 第三，AI 安全：输入审查、提示词注入拦截、异常信息脱敏。
> 第四，本地优先：SQLite 单文件、报告按账号隔离、一条命令启动，不依赖云服务。

### 06:40–07:00 收尾（20 秒）

**画面**：回到首页 / 团队信息页。

**口播**：

> 以上就是极构需求诊断顾问。它让不懂技术的人，也能先把需求想清楚，再去找开发。
> 谢谢大家。
